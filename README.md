# Unemployment-Analysis-With-Python-
This analysis covers 20 Indian states across 10 months (January -October 2020). The dataset extends coverage to May 2019, enabling pre-pandemic baseline comparison. Both rural and urban unemployment segments are examined.
Tools and Libraries used : 
* python
* Jupiter Notebook 
Python Libraries 
*pandas
*Numpy
*Matplotlib 
*seaborn
*warnings
